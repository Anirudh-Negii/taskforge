# TaskForge

> **Forge Your Tasks. Shape Your Productivity.**

TaskForge is a modern task management application built with HTML, CSS, and JavaScript. It provides a simple and intuitive way to organize tasks, track progress, and stay productive through a clean interface with persistent storage and theme customization.

###  Live Demo →  https://taskforge-task-manager.vercel.app

## Features

* Create, edit, complete, and delete tasks.
* Organize tasks into categories.
* Search and filter tasks with real-time results.
* Track pending and completed tasks with live counters.
* Switch between light and dark themes.
* Automatically save tasks and preferences using local storage.
* Clear all tasks with a single action.
* Responsive design with smooth interactions and animations.

## Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)

## Future Improvements

- Add task priorities to help organize work more effectively.
- Support due dates and reminders for better task planning.
- Enable drag-and-drop functionality to reorder tasks.
- Provide a task statistics dashboard to visualize productivity.
